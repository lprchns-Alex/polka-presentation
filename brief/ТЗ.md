# ТЗ: переделать презентацию «Полка»

Сайт: https://lprchns-alex.github.io/polka-presentation/ (репозиторий `polka-presentation`).

## Коротко

Оформление оставляем: шалфейный фон, «листы» позади слайда, тонкий гротеск, обводные подписи, нижняя панель (обзор, текст выступления, PDF, полный экран). Оно получилось хорошо.

Меняем содержание. Сейчас почти все экраны — **ранний веб-прототип**, а результат проекта — **нативные приложения Полки для Mac и iPhone**. Показать нужно их. Новые экраны лежат в папке `картинки/` рядом с этим ТЗ.

Выступление — **4–5 минут** (сейчас 6). Аудитория — одногруппники и преподаватели курса: им интересен и продукт, и путь, и то, как дизайнер сделал приложение с ИИ.

## Что исправить

1. Почти везде веб-прототип вместо настоящих приложений. Веб-прототип оставить **только** на слайде про развитие проекта.
2. Убрать **®** у слова «Полка»: товарный знак не зарегистрирован.
3. Убрать слайд «Просмотр внутри» с чужим роликом (лица, «GPT-6 Astra + Миша Наер»).
4. План на слайде «Следующий этап» придуман. Заменить на настоящий (ниже).
5. Подписи-таблетки, сноски и надписи в шапке слишком мелкие. Презентацию будут показывать через демонстрацию экрана, поэтому самый мелкий текст должен быть **не меньше 18 px** при ширине окна 1600 px.
6. Убрать подписи «экраны раннего веб-прототипа» и «Версия с ранними экранами» везде, кроме слайда про развитие.

## Факты — только эти, ничего не придумывать

- **Полка** — библиотека для всего, что сохраняешь «на потом»: статьи, видео, референсы, файлы. Помогает не только сохранить, но и **вернуться** к сохранённому.
- Для кого: дизайнеры и креативщики, которые копят материалы и не возвращаются к ним. Это гипотеза, её ещё проверять.
- **Mac:** приложение на Swift по гайдлайнам Apple.
  - Сохранить ссылку из любой программы — ⌃⌥⌘D, появляется окно «Добавить на полку». Название, обложку и текст Полка загружает сама.
  - Входящие, коллекции, теги, «зачем сохраняю», избранное, «отложить».
  - Главная с подборкой «Есть время»: выбираешь, сколько есть минут, Полка предлагает, что успеешь.
  - Читалка внутри приложения: статьи, PDF, видео; перевод на русский встроенным переводчиком Apple; цитаты и заметки.
- **iPhone:** та же библиотека. Mac выкладывает копию в iCloud Drive, телефон её читает. Ссылку можно сохранить из Safari через «Поделиться». Есть читалка с переводом. С 26 октября Полка стоит на телефоне автора.
- Данные хранятся только у человека: без серверов и аккаунтов.
- **Путь:**
  - сентябрь — веб-прототип 0.2, автор пользовался им сам;
  - 17 октября — начал заново на Swift, нативное приложение для Mac;
  - 19 октября — бета 0.4.0: установщик, первая тестировщица;
  - 24–26 октября — iPhone-версия, аккаунт разработчика Apple, Полка на настоящем телефоне.
- **Цифры:**
  - 76 точек сохранения в git;
  - 67 автотестов (58 для Mac и 9 сценариев для iPhone);
  - около 9 300 строк кода на Swift;
  - 0 серверов.
- **Работа с ИИ:**
  - автор — продукт и дизайн: идея, интерфейс, решения, проверка руками;
  - Claude Code — приложения на Swift, тесты, сборка;
  - Codex и ChatGPT — веб-прототип и ручные проверки.
- **Что понял:**
  - системный интерфейс Apple — быстрее и лучше своего;
  - ИИ нужны рамки: план, сохранение после каждого шага, записанные решения;
  - симулятор ловит не всё — проверять на живом телефоне (на телефоне нашлась ошибка с обложками, которой не было в симуляторе).
- **Дальше:**

  - ноябрь — iPhone через TestFlight;
  - конец ноября — большая бета, 20–50 человек;
  - дальше — лендинг на русском и английском, запуск.

## Анимации взаимодействия

Короткие, на CSS, крутятся по кругу, пока слайд открыт:

- **Слайд 4.** Появляются клавиши ⌃ ⌥ ⌘ D и по очереди «нажимаются». Затем выезжает окно `mac-quick-save.png`. Потом во входящих появляется новая карточка: сначала серая заглушка с мерцанием, затем обложка и название.
- **Слайд 5.** Переключатель «5 мин · 15 мин · 30 мин · Час» сам переезжает по пунктам, список из трёх находок под ним меняется. Можно нарисовать на HTML/CSS в стиле интерфейса Полки (системный шрифт, оранжевый #ff3d00 только для выделения).
- **Слайд 7.** На макете телефона снизу выезжает меню «Поделиться», нажимается иконка «Полка», сверху появляется «✓ Сохранено на Полку».

Требования к анимациям:
- уважать `prefers-reduced-motion`: тогда показывать последний кадр без движения;
- PDF не должен ломаться: в нём — статичный финальный кадр.

## Технически

- Картинки положить в `assets/`. Старые файлы веб-прототипа оставить только для слайда 8.
- Mac-скриншоты — PNG с прозрачной тенью: ставить на светлую карточку, не обрезать.
- iPhone-скриншоты уже в корпусе телефона: рамку не дорисовывать.
- Проверить ширины 1600 и 1280 px, а также PDF.
- Публиковать на GitHub Pages только после того, как автор посмотрит.
