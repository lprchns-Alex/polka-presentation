# Полка — презентация проекта

Браузерная презентация о нативных приложениях Полки для Mac и iPhone: 10 слайдов, 4 минуты 35 секунд.

## Версия 2.0.0 · 28 октября 2026

[Открыть презентацию](https://lprchns-alex.github.io/polka-presentation/#1) · [Скачать PDF](https://lprchns-alex.github.io/polka-presentation/polka-presentation.pdf) · [Релиз v2.0.0](https://github.com/lprchns-Alex/polka-presentation/releases/tag/v2.0.0)

Содержание пересобрано по `brief/ТЗ.md` и просмотрено автором. Вместо ранних экранов веб-прототипа показаны настоящие приложения Mac и iPhone. Предыдущая презентация сохранена в теге `v1.0.0`; текущая — в `v2.0.0`.

- `index.html` — открыть в браузере. Всё работает локально, без сборки и внешних зависимостей.
- `polka-presentation.pdf` — резервная версия: 10 страниц, финальные кадры анимаций.
- `speaker-notes.txt` — текст выступления и тайминг.
- `slides.js` — содержание слайдов и заметки.
- `style.css` — оформление и три схемы взаимодействия.
- `app.js` — навигация, обзор и заметки.
- `assets/` — 13 оригинальных PNG приложений и 3 исторических JPG веб-прототипа.
- `brief/ТЗ.md` — неизменённое исходное ТЗ.

## Управление

← / →, пробел, Page Up / Page Down — листание. Home / End — первый / последний слайд. O — обзор, N — текст выступления, F — полный экран, Escape — закрыть заметки / обзор. На сенсорном экране — свайп.

Заметки видны в том же окне: перед демонстрацией экрана закройте их. Слайды не переключаются сами; анимации взаимодействия зациклены только на открытом слайде.

## Экраны и анимации

Mac-скриншоты показаны целиком на светлой поверхности. iPhone-скриншоты уже содержат корпус телефона. Веб-прототип используется только на слайде 8.

На слайдах 4, 5 и 7 короткие CSS-схемы показывают сохранение по ⌃⌥⌘D, подборку «Есть время» и сохранение через «Поделиться». Это иллюстрации последовательности действий, не видеозаписи приложения. Подборка использует условные типы материалов без выдуманных названий и длительности.

При системной настройке «Уменьшение движения» и в PDF показаны финальные статичные состояния. В обзоре и скрытой вкладке анимации приостановлены.

## Важные факты

iCloud Drive используется для копии библиотеки: Mac записывает, iPhone читает. Презентация не обещает двустороннюю синхронизацию. Роли: автор — продукт и дизайн; Claude Code — Swift-приложения, тесты и сборки; Codex и ChatGPT — веб-прототип и ручные проверки. Числа и планы приведены по ТЗ автора.

## Локальный запуск

```sh
python3 -m http.server 4418 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:4418/`. Для статичного кадра без панели управления — `?capture=1#1` (номер в конце — нужный слайд).
